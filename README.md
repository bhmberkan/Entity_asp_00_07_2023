# 📌 Entity ASP.NET Projesi

Entity_asp_00_07_2023, ASP.NET  ve Entity Framework kullanılarak geliştirilmiş bir web uygulamasıdır. Bu proje, veritabanı işlemlerini kolaylaştıran Entity Framework'ü kullanarak CRUD (Create, Read, Update, Delete) işlemlerini gerçekleştirmek için tasarlanmıştır.
Ayrıca belirli istatistik bilgilerini de yapmaktadır. Mvc mimarisi kullanılmamıştır. Proje backend olarak geliştirilmiş olup tasarımsal olarak bir tema oluşturulmamıştır.

## 🚀 Proje Özellikleri

- 🔹 **Entity Framework Core ile veritabanı yönetimi**
- 🔹 **ASP.NET  kullanımı**
- 🔹 **LINQ sorguları ile veri işlemleri**
- 🔹 **Dinamik içerik yönetimi**
- 🔹 **Modern ve kullanıcı dostu arayüz**
- 🔹 **POPUP kullanımı**

## 🛠️ Kullanılan Teknolojiler

- **ASP.NET**
- **Entity Framework**
- **SQL Server**
- **LINQ**
- **Bootstrap & CSS**

## 🔧 Kurulum

1. **Projeyi klonlayın:**
   ```sh
   git clone https://github.com/bhmberkan/Entity_asp_00_07_2023.git
   ```
2. **Bağımlılıkları yükleyin:**
   - Gerekli NuGet paketlerini yükleyin.
3. **Veritabanını yapılandırın:**
   - `appsettings.json` dosyasında bağlantı stringini güncelleyin.
   - Migration işlemlerini gerçekleştirin:
     ```sh
     dotnet ef migrations add InitialCreate
     dotnet ef database update
     ```
4. **Projeyi çalıştırın:**
   - Visual Studio veya uygun bir IDE kullanarak projeyi başlatın.
